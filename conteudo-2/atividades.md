## Questões de estudo

1. Explique o que é assincronismo no Javascript.
2. O que são APIs?
3. Cite 3 métodos HTTP e explique para o que servem.
4. Quais são os 3 tipos de declaração de variáveis?
5. Utilizando a Star Wars API ([https://swapi.dev/](https://swapi.dev/)) desenvolva o seguinte algoritmo em JS e NodeJS.\
   a. Pegue todos os dados do personagem ‘Darth Vader’ e mostre na tela.\
   b. Após, mostre qual é a nave que ele pilota.\
   c. Após, indique em qual filme ela aparece.\
   d. E por fim, mostre na tela o opening crawl (texto de abertura) deste filme.\
   e. Faça o tratamento de erros para evitar problemas nas chamadas.
