## Questões de estudo

1. Qual a diferença entre apps hibridas e apps nativas?
2. Cite 3 vantagens de usar o React Native.
3. Qual é a base de linguagem para o React Native?
4. Qual a linguagem que permite executar código Javascript no servidor?
5. Quais são as 5 tipagens básicas do Javascript?
6. Desenvolva um algoritmo que classifica e conta números em uma lista conforme sua categoria: positiva ou negativa. O algoritmo deve usar estruturas de controle `if`, `else if` e `else` para classificar os números e um loop `for` para iterar através da lista, ao final do código, imprima quantos números tiveram em cada categoria.
7. Cite dois padrões de nomenclatura e explique como deve ser escrito.
8. Cite um exemplo de boa prática no desenvolvimento.
