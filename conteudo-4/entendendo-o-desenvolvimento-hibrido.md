# Entendendo o desenvolvimento híbrido

<figure><img src="../.gitbook/assets/React Native (4).png" alt=""><figcaption></figcaption></figure>

No uso popular, muita gente chama React Native de “híbrido”, mas vale fazer uma distinção:

* tecnologias híbridas clássicas costumam renderizar a interface em WebView;
* o React Native trabalha com componentes nativos e uma camada JavaScript.

Por isso, é mais preciso dizer que ele é uma solução **multiplataforma** com renderização nativa.

## O que isso significa na prática

Com React Native:

* você escreve grande parte da lógica uma vez;
* compartilha código entre Android e iOS;
* continua entregando interface com comportamento próximo ao nativo.

## Benefícios principais

* redução de retrabalho;
* manutenção mais simples;
* velocidade maior para validar projetos;
* ecossistema forte.

## Nova arquitetura do React Native

O React Native moderno também evoluiu internamente com elementos como:

* **JSI**
* **TurboModules**
* **Fabric**

Você não precisa dominar esses detalhes para começar o curso, mas é importante saber que o ecossistema segue evoluindo para melhorar performance e integração nativa.

## Conclusão

Para o curso, o ponto mais importante é este: React Native permite criar aplicativos reais com JavaScript e componentes nativos, equilibrando produtividade e experiência mobile.
