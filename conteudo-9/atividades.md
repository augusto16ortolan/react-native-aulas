## Questões de estudo

1. O que é a Context API e qual problema ela resolve no React/React Native (especialmente o “prop drilling”)?
2. Qual a diferença entre criar um contexto (`createContext`) e fornecer valores com o `Provider`?
3. Como consumir valores do contexto usando `useContext`, e por que costuma ser uma boa prática criar um hook como `useAppSettings()`?
4. Em quais situações a Context API é indicada (tema, idioma, autenticação) e em quais casos ela não é a melhor escolha (estado que muda o tempo todo, formulários grandes)?
5. Como evitar re-renderizações desnecessárias ao usar Context API (por exemplo, com `useMemo` no `value` e separando contextos por responsabilidade)?
