## Questões de estudo

1. Explique para o que serve o método map.
2. Explique para o que serve o método filter.
3. Explique para o que serve o método reduce.
4. Explique para o que serve a destruturação de objetos.
5. Escreva um algoritmo em JavaScript para consultar a API fornecida e filtrar os dados para encontrar todos os usuários do sexo masculino. Em seguida, monte o nome completo de cada usuário e imprima o resultado na tela.\
   1\. Consultar a API: Use a URL https://randomuser.me/api/?results=20 para obter uma lista de 20 usuários aleatórios.\
   2\. Filtrar Usuários Masculinos: Extraia todos os usuários cujo gênero é masculino (gender).\
   3\. Montar Nome Completo: Para cada usuário masculino, crie uma string com o nome completo no formato "Primeiro Nome Último Nome".\
   4\. Imprimir Resultados: Exiba todos os nomes completos dos usuários masculinos na tela.
